## Running on Docker Without Compose (`docker-without-compose` branch)

This branch contains a setup to run all microservices, PostgreSQL databases, API Gateway, and frontend using pure **Docker CLI** commands without Docker Compose.

### Quick Start
- **Windows (PowerShell)**: Run `.\run-docker.ps1` (Stop: `.\stop-docker.ps1`)
- **Linux / macOS (Bash)**: Run `./run-docker.sh` (Stop: `./stop-docker.sh`)

For full manual CLI reference commands, see [DOCKER_WITHOUT_COMPOSE.md](file:///c:/Users/Anosh/Documents/Notes/Projects/Cloud_Computing/Ecommerce/DOCKER_WITHOUT_COMPOSE.md).
